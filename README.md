一款**完全离线、零权限**的安卓本地漫画阅读器：直接读取手机文件夹里的 `.zip` / `.cbz` 漫画包，点开即看，**不把图片解压到磁盘**。

支持 Android 9（API 28）到最新版本。界面采用 Material 3 Expressive 风格。

## 它和普通看图软件有什么不一样

普通做法是把压缩包解开、在手机上生成一堆图片文件，既占空间又慢。这个应用只做三件事：

1. 读压缩包的**目录表**，排出页码顺序（不读图片内容）；
2. 翻到某一页时，只把**那一页**的压缩数据在内存里展开、解码成图像；
3. 翻走就释放，磁盘上始终只有原来那个压缩包。

因为用的是可随机定位的文件描述符，即使是几个 GB 的大包也**不需要先复制一份**，不会额外占用存储空间。

> 唯一无法避免的是：屏幕要显示画面，必须把当前页在内存里解码成位图。这是任何看图软件都躲不掉的一步，但只在内存里临时存在，不会写成文件。

## 主要功能

- 选一次漫画文件夹，长期记住；打开应用就是书架
- Material 3 底部图标导航（书架 / 在读，图标 + 文字 + 跟手滑动的选中指示器），可点击切换，也可左右滑动切换；在读页只显示翻过页且未看完的漫画（只打开封面、或翻回第一页都视为未读）
- 书架可选每排 2 / 3 / 4 / 5 本（默认 2），列数多时封面卡片自动紧凑排版
- 7 种排序：名称升/降、修改时间新/旧、体积大/小、最近阅读；搜索框旁下拉即选
- 可折叠大标题栏：标题字号 / 字重 / 透明度随滚动连续插值，工具栏固定不消失，收到底只留搜索框与排序 / 列数 / 刷新 / 设置；下滑反向渐进展开；滚动后出现「回到顶部」圆形按钮；两页各自保留滚动位置
- 自动扫描 `.zip` / `.cbz` / `.rar` / `.7z` **和已经解压出来的图片文件夹**（都含子文件夹，几种可以混在同一个目录里），封面缩略图、搜索、真实阅读进度（第 x / y 页 + 进度条；翻过页才记录，翻回第一页清除记录视为未读，返回书架立即刷新）
- 文件夹类漫画与压缩包完全同权：直接列目录里的图片按文件名自然排序当页，不复制、不搬动、不生成任何临时文件，页数和进度照样记录；书架上用「文件夹」代替体积显示
- **可以添加多个漫画文件夹**（设置 →「漫画文件夹」→ 添加），机身存储、SD 卡、按作者或按类型分开放的书库会汇总到同一个书架；`zip`、`rar`、`7z`、图片文件夹混着放也没关系
- **按分类筛选**：每个文件夹下的第一层目录名自动成为书架的「分类」筛选（作者名、类型名、系列名都行），点一下只看这一类
- 书架索引持久化：冷启动先显示记住的书架，后台静默增量核对，几千本也不用等重新整理；「刷新」按钮可立即重查；扫描上限 10 万本、目录深度 12 层
- 封面跨启动缓存 + 按列数降采样（160～360 px）+ 并发生成限流，一排 5 本也不卡顿
- 动效遵循「连续状态」原则：指示器跟手滑动并带形状挤压，颜色 / 圆角 / 字号由同一个连续进度插值；页面水平推入带视差，短促 ease-out + 形状形变，并尊重系统「减少动画」设置
- 不解压直读，支持 ZIP64 大包（> 4 GB）
- 自动识别 UTF-8 / GBK / Shift_JIS 文件名，中文、日文包名不乱码
- 页码按自然顺序排（`第2页` 在 `第10页` 前面），自动跳过说明文件
- 支持 jpg / png / webp / gif / bmp / heic / avif 等常见格式
- 右→左（日漫）或左→右翻页、单页 / 双页、轻点左右边缘**可快速连点**翻页（可关，带方向反馈）、双指缩放、双击复原
- **两种阅读模式**：翻页（单页 / 双页、左右方向）与**卷轴**（连续下滑，专为韩国条漫等超长图设计）。卷轴模式把几万像素高的长图按约 1000 px 切成小块，只解码屏幕上能看到的那几块，页与页之间无缝衔接；打开书时只扫描图片头（每页约 64 KB）就能算出整本的长度
- 卷轴模式下：上下滑动连续阅读、点左右侧滚动一屏、页数条跳页、首页 / 上一页 / 下一页 / 末页；进度同样按「当前所在的那一页」记录，滑回第一页即视为未读
- **缩放方式七选一**，翻页与卷轴都生效：原始尺寸（1:1 像素）、符合屏幕（整页可见）、符合宽度、符合高度、固定缩放（40%–400% 可调）、伸展（填满、不保比例）、覆盖（填满、保比例、裁掉多余）；页面比屏幕大时可直接拖动查看，窄边不足时滑动手势仍用于翻页
- 其它阅读选项：**原点设置**（水平置中 / 靠左 / 靠右）、**屏幕方向**（跟随系统 / 直立 / 横屏）、**图像平滑方式**（平滑 / 锐利）、**背光控制**（跟随系统，或只在应用内单独调亮度，不改系统设置）
- **设置分两层**：书架右上角打开的是设置菜单（阅读设置 / 漫画文件夹 / 个性化 / 书架列数 / 清除进度 / 关于），阅读项统一收进「阅读设置」子页，个性化项收进「个性化」子页；阅读器里的齿轮按钮直接跳到阅读设置。窗口是居中的**毛玻璃悬浮窗**（不是全屏面板，也不铺满整块屏幕）：只有窗口范围内的画面是虚化的，窗口以外保持清晰，文字不会压在花纹上，改一项也能立刻看到周围的画面变化
- **返回键分层**：阅读时按返回先关设置窗口，再收起工具条，最后才退出到书架
- 阅读器底部控制栏：可横向滑动的**页面缩略图预览**（点选跳页、当前页高亮、独立小图缓存）、日漫模式**镜像页数条**与两端页码、首页 / 上一页 / 下一页 / 末页、单双页与方向快捷切换、收起工具条
- 所有设置即时生效（单一可观察状态源），自动记住看到第几页，屏幕常亮，全屏沉浸
- **六套清新主题颜色**：抹茶绿（默认）、湖水青、晴空蓝、薰衣草、樱花粉、蜜桔橙。低饱和的浅色纸面 + 明亮干净的点缀色，不把整块背景染成深色；按钮、选中态、进度条、分段控件一起变色，浅色 / 深色各有一套对应配色，切换时颜色渐变过渡
- **四种翻页动画**（在「阅读设置」里选）：滑动（默认，横向推开）、淡入淡出、翻书（新页绕书脊 3D 翻入）、缩放（轻微放大显现）。翻书时书脊固定在同一侧，往回翻是同一个翻页动作反着放，不会镜像到屏幕另一边；换到「右 → 左（日漫）」时书脊移到右边，但**翻到下一页一律从下往上翻上来、翻回上一页一律从上往下翻下去**，两种方向下视觉逻辑一致；翻页时下方始终压着一整张已显示的页面，所以动画中途不会出现黑屏；点两侧翻页、滑动翻页、页码条跳页都能看到；卷轴模式是连续滚动，不参与翻页动画
- 浅色 / 深色 / 跟随系统
- 高清大图按屏幕降采样 + 像素预算，避免闪退；相邻页预取

## 权限与隐私

**源码 Manifest 里没有声明任何权限**，包括网络权限和存储权限，运行时也不会向用户弹出任何授权弹窗。

> 打包后 AndroidX 会自动合并一条应用自用的签名级权限 `DYNAMIC_RECEIVER_NOT_EXPORTED_PERMISSION`，用于保护动态广播接收器；它由系统自动管理，不需要用户授权，也不涉及文件、网络或个人数据。

文件访问通过系统自带的文件夹选择器（Storage Access Framework）完成：用户主动选一次文件夹，应用只对这一个文件夹获得读取授权，并通过 `takePersistableUriPermission` 长期保留。应用不联网、不上传、不改动原压缩包。

**关于 RAR 的临时文件**：rar 的读取库要求一个真实路径，正常情况下用的是已打开的文件描述符（`/proc/self/fd`），不产生任何副本；只有网盘这类只能顺序读的目录，才会在应用私有缓存 `cacheDir/rar` 里临时放一份，关掉这本书立即删除。

**关于封面缓存**：漫画页始终只在内存里解码，不写入磁盘。唯一的例外是封面缩略图——320 px 宽的小 JPEG，保存在应用自己的私有缓存目录 `cacheDir/covers`，这样退出重进不必反复解包读封面。它不在漫画文件夹里、不是漫画原图、卸载应用时随私有数据一起删除，也不会占用漫画包的双倍空间（100 本大约几 MB）。系统空间紧张时会自动清理这个目录。

**关于书架索引**：`filesDir/shelf_index.json` 只保存每本书的文件 URI、名称、字节数和修改时间，**不含任何漫画内容**，不写进漫画文件夹，也不联网。它让冷启动直接显示上一次的书架，后台再静默核对一次目录（只有增删改才更新列表并重写索引）；扫描结果为空而缓存非空时视为临时授权问题，绝不把好书架清空。换文件夹自动作废，卸载应用时一并删除。

## 关于流畅度

之前手机上装的是**调试版**。调试版为了方便排错，不做代码优化、不做预编译，Jetpack Compose 在这种模式下每帧都要多干很多活，所以功能不多也会掉帧；而成熟软件发布的是**正式版**，还会把滚动、布局这些常用路径提前编译成机器码。现在提供的 APK 就是正式版：

- 打开代码优化（R8）与无用资源清理，APK 从 27.6 MB 降到 2.6 MB，只保留一个 dex；
- 接入 AndroidX 基线配置（打包进 `assets/dexopt/baseline.prof`），系统空闲时会预编译热点代码；
- 和旧版用同一个签名，**直接覆盖安装即可**，书架与阅读进度不会丢。

代码层面也修掉了真正会造成掉帧的地方：

| 之前 | 问题 | 现在 |
| --- | --- | --- |
| 当前页、相邻页、底部预览条十几张图同时开协程解压 | 同一个 zip 只能排队读，正在看的那一页反而要等十几张小图 | 单一 worker + 三级优先队列：当前页 > 相邻页 > 预览条；重复请求合并，滑出屏幕的预览直接跳过 |
| 预览缩略图按整页规格解码 | 52 dp 的小图却解出约 500 px 位图 | 更紧的采样，解码尺寸约为原来的 1/4 |
| 每次解压都从 256 KB 缓冲区反复扩容 | 10 MB 的一页要复制七八次 | 按 zip 记录的原始大小预分配 |
| 每次开书都试 3 种文件名编码 | 大包目录表被解析 3 次 | 记住上次胜出的编码，重开通常只解析 1 次 |
| 双指缩放每帧读写状态 | 整个阅读器（含预览条、页数条、按钮）每帧重算 | 只在跨过清晰度阈值时重算；点击提示只在动画期间组合，不每帧重组 |
| 书架滚动时整页跟着标题一起重算 | 标题变一点，搜索框、下拉菜单、整个网格都跟着重组 | 滚动进度只在标题栏内部读取，网格完全不参与 |
| 封面即使已在内存里也要排队等线程池 | 快速滚动时协程排长队、封面闪一下 | 命中缓存同步返回；磁盘缩略图按显示尺寸采样解码 |
| 搜索时每敲一个字都重排全部书目 | 自然排序对几千本很贵 | 先排一次序，之后只做筛选 |
| 底部导航跟手滑动时整块导航重算 | 滑动过程掉帧 | 只有两个小标签重算，指示器只改绘制层 |

页面 / 缩略图 / 封面三份内存缓存上限由 96 + 24 + 48 MB 调整为 48 + 8 + 32 MB，
减少大位图反复分配引起的垃圾回收抖动；翻页或切换清晰度时先显示已有的低清图，
高清图在后台补上，不再白屏转圈。

## 超长条漫怎么读

在「阅读设置 → 阅读模式」里选**卷轴**（阅读器底部工具条也有快捷按钮）。然后：

1. 直接上下滑动，整本连续往下走，不用一页一页点。
2. 点屏幕左 / 右侧滚动一屏，点中间显示或收起工具条；底部页数条可以跳到任意一话。
3. 条漫建议「直立」+「符合宽度」；图片比屏幕窄时用「原点设置」调对齐。

为什么以前看长图费劲：一张条漫可能是 800 × 20,000 px，按「一页一张图」解码需要约 64 MB 位图，
还常常超过显卡纹理上限，结果要么糊、要么卡、要么直接打不开。现在的做法：

- 打开书时只解压每页**前 64 KB** 的图片头，读出原始宽高，很快就能算出整本要铺多长；
- 按显示宽度把长图切成约 1000 px 高的横向条带，用 `BitmapRegionDecoder` **只解码当前可见的条带**；
- 同一页解压后的数据只留一份，供它的所有条带复用；滚动离开的条带请求直接跳过；
- JPEG / PNG / WebP 走区域解码，HEIF / AVIF 等新格式用 `ImageDecoder` 裁切，实在不支持时再退回「整图缩小后裁切」，保证不会空白；
- 整页解码的像素预算同时从 1600 万降到 800 万，翻页模式下误开超长图也不会一次吃掉几十 MB。

整个过程中漫画页依然**只在内存里**，磁盘上始终只有原来的压缩包。

## 实现要点

- `PageSource`：把「一本漫画」抽象成 `pageCount` / `readHeader` / `readPage` 三个方法，zip（`ArchiveReader`）、图片文件夹（`FolderReader`）、rar（`RarReader`）、7z（`SevenZReader`）各自实现，阅读器、卷轴模式、封面生成三条链路都不必区分来源。
- `SevenZReader`：Commons Compress 的 `SevenZFile(SeekableByteChannel)` 直接读 7z，不需要先解压；solid 压缩块会按块推进，随机跳页时只多解一个块。
- `RarReader`：junrar 需要一个真实文件，所以把文档描述符以 `/proc/self/fd/<n>` 的形式交给它（RAR 的索引本身就在文件里，可随机定位），只有少数只能流式读取的网盘目录才会先在应用私有缓存里临时放一份，退出这本书立刻删除。
- `ArchiveReader`：用 `ContentResolver.openFileDescriptor` 取得可定位的文件描述符，交给 Apache Commons Compress 的 `ZipFile(SeekableByteChannel)`，实现按条目随机读取；支持 ZIP64、编码探测、偏移通道。
- `FolderReader`：用 `DocumentsContract.buildChildDocumentsUriUsingTree` 列出子目录里的图片（`DocumentFile` 无法可靠列出子目录），按自然顺序排出页码，每页用 `openInputStream` 读一次；`readHeader` 只读前 64 KB，所以卷轴模式依然能快速算出整本长度。
- `PageDecoder`：`BitmapFactory` 优先（可按采样率降采样），`ImageDecoder` 兜底新格式，统一受 800 万像素预算约束；新增 `bounds()`（只读图片头）、`decodeRegion()`（区域解码长图条带）、`decodeWhole()`（新格式兜底：整图缩小后裁切）。
- `ArchiveReader.readHeader()`：只解压条目前 64 KB，卷轴模式据此在打开书时快速建立全部页的宽高表，不必把几百张长图全部展开。
- `data/ZoomMode.kt`：七种缩放方式的唯一来源；`PagePane` 按模式算出绘制尺寸（1:1 / 填宽 / 填高 / 百分比 / 填满 / 覆盖），超出视口时按轴向挂载拖动识别——只纵向溢出时只认纵向拖动，保证横向滑动仍能翻页
- `ui/WebtoonScreen.kt`：`buildTiles()` 依据每页宽高与缩放方式生成全局条带列表，`LazyColumn` 连续排列、只请求可见条带；进度按顶部可见条带所属的页记录。点击识别只观察指针事件、**不消费**按下事件，避免吞掉列表自身的滑动（页模式曾踩过这个坑）。
- 解码结果放在按字节计数的 `LruCache` 中：整页 48 MB、预览缩略图 8 MB，互不挤占；漫画页不落盘。`PageDecoder` 对缩略图启用更紧的采样（`tight`），并对超大图保留 1600 万像素预算。
- `ComicRepository`：封面缩略图以 320 px JPEG 存入应用私有缓存目录，跨进程重启复用；进程级 32 MB 字节上限内存缓存放在 `CoverMemoryCache` 单例中（不随 Activity / ViewModel 重建丢失）。命中内存缓存时 `cover()` 同步返回，不切换线程；`peekCover()` 让卡片在重组瞬间就有图可画；磁盘缩略图按目标尺寸 `inSampleSize` 一次解码到位。`Dispatchers.IO.limitedParallelism(2)` 限制同时打开压缩包的数量；书架按列数请求 160 / 200 / 260 / 360 px 缩略图；目录遍历上限 10 万本、深度 12 层。
- `ShelfIndex` + `ShelfViewModel`：启动时先从私有 JSON 索引恢复书架（无阻塞等待），读索引的短暂间隙用 `restoring` 状态避免闪出「还没有漫画」；再在 IO 线程静默遍历目录并按 URI / 名称 / 大小 / 修改时间做增量比对；只有真正发生变化才更新列表与索引；30 秒内的 Activity 重建跳过重复遍历；空扫描结果不会误清缓存。
- `Prefs`：阅读进度以「当前所在页」为准，第 0 页删除该书的页码、总页数和最近阅读时间（未读）；在读筛选使用一次性的 `progressSnapshot()`，避免几万本书逐条读存储。
- `ReaderScreen`：Compose `HorizontalPager` + `reverseLayout` 实现日漫方向，缩放时禁用翻页手势；点击 / 缩放检测都挂在 pager 自身的 `pointerInput` 链上（覆盖式点击层会吞掉拖动导致滑动失效）。
- 连续点击翻页：`animateScrollToPage` 会让 `currentPage` 在整个动画期间滞后，快速连点会反复算到同一目标页。改为同步递增的 `requestedPage` + `scrollToPage`（瞬时吸附），每次点击先累加目标再启动跳转，并取消上一个未完成的跳转；手指滑动导致的页面变化在 pager 稳定后才回写 `requestedPage`。
- 页面预览条：`LazyRow` + `produceState` 只解码可见项，`ReaderViewModel.thumbnail()` 用独立的 8 MB 小图缓存（与 48 MB 全屏页缓存隔离，避免大图被挤掉或把小图当整页显示）；滑出屏幕的预览会被工作队列跳过。日漫模式 `reverseLayout = true`，页数条用 `graphicsLayer { scaleX = -1f }` 镜像、两端页码互换。
- `ReaderViewModel` 的三级优先队列（当前页 > 相邻页 > 预览条）由一个 IO worker 串行消费：一个 `ZipFile` 本来就只能排队读，并发开协程只会互相抢锁并拖慢正在看的那一页。请求按缓存 key 去重，换书时作废所有在途请求；`peekPage()` 让画质切换 / 翻页先显示旧图，不白屏。
- 切换单 / 双页或翻页方向时 `key(...)` 重建 pager，避免页数减半后索引越界。
- 主题配色：六套手工选的明亮点缀色共用一套中性骨架，浅色是近乎纯白的纸面（只掺 2.5% 点缀色），深色是冷调炭灰；容器色由点缀色按比例混合出来，所以每套配色的对比度一致、不会一块发闷。`Theme.kt` 的 `animatedColorScheme()` 在切换时对每个颜色做插值，换色是渐变而不是闪一下。
- 翻页动画：`HorizontalPager` 的页面位置用与 `PagerState.getOffsetDistanceInPages` 相同的公式 `(页码 - 当前页) - 偏移比例` 计算，抵消掉 pager 自带的横移后，页面就能在原地做淡入淡出、绕书脊 3D 翻转或缩放显现。翻页开始前停在屏幕上的那一页会作为不透明底板一直压在下面，只有新页在上层做动画，任何时刻都不会露出黑底；翻书模式的书脊边固定（左→右漫画在左、右→左漫画在右），往回翻时旋转符号取反，等于把同一个翻页动作倒放，而不是把动画镜像到另一边；书脊换边会连带镜像透视，所以旋转符号还要再乘一个方向因子，保证两种阅读方向下「下一页从下往上、上一页从上往下」不颠倒；翻页动画时长与系统「减少动画」设置共用同一套曲线。
- 设置窗口的毛玻璃：只虚化卡片本身，卡片以外一概不动。做法是打开窗口前对窗口拍一张快照（`ui/Backdrop.kt`），缩到 1/8 后连做三遍盒式模糊、再放大绘制，1080×2340 的屏幕只有约 3.9 万像素需要计算；快照按卡片在窗口中的实际位置平移，玻璃里显示的就是它正下方那一块画面。换主题后快照的颜色会过期，此时窗口退回接近实心的样式，下次打开重新拍摄。
- `UiSettings`：把设置项包装成可观察状态并与 `SharedPreferences` 同步写入，避免设置面板需要重新打开才刷新。
- `MainActivity` / `ShelfScreen`：主界面横向分页 + Material 3 风格底部图标导航（单个指示器跟手滑动、图标与文字按连续 selection 插值）；在读页按「当前页码 > 0 且未到最后一页」筛选，只打开第一页或翻回第一页都不写进度、不显示进度条；两页共用排序与列数、各自保留滚动状态。
- 折叠大标题：一个 `NestedScrollConnection` 产出 0..1 的连续 `collapse`，同时驱动可折叠区高度、标题字号（28→20sp）、字重（700→500）与透明度；工具栏始终固定（搜索 / 排序 / 列数 / 刷新 / 设置），收到底即只剩这一行；`derivedStateOf` 控制「回到顶部」圆形按钮的出现。滚动进度只在 `CollapsingHeader` 内部读取，避免每帧重算整个网格。没有二值弹出，也没有两段互相打架的补间。书目只在排序方式 / 书库变化时排序一次，搜索仅做筛选。
- `ui/Motion.kt`：统一的曲线、时长与系统动画缩放。所有视觉状态由一个连续位置值（手势进度或 `animateFloatAsState`）推导出 `selection`，再用 `lerp` 插值颜色、圆角和尺寸；只有「按下」这类离散事件才播放短补间。书架 → 阅读器用水平推入 + 旧页视差，而不是交叉淡入。

## 项目结构

```
app/src/main/java/com/yingcolor/comicviewer/
├── MainActivity.kt        入口与页面切换
├── UiStrings.kt           全部界面文案
├── theme/Theme.kt         M3 Expressive 形状 / 动效 / 配色过渡
├── theme/Palettes.kt      六套清新主题配色（中性骨架 + 点缀色混合）
├── data/
│   ├── PageSource.kt      zip / rar / 7z / 文件夹 四种页面来源
│   ├── ArchiveReader.kt   zip 直读核心
│   ├── PageDecoder.kt     图片解码与内存控制
│   ├── ComicRepository.kt 扫描书架、封面缓存
│   ├── ShelfIndex.kt      书架索引持久化（秒开）
│   ├── Prefs.kt           设置与阅读进度
│   ├── PageAnimation.kt   四种翻页动画的常量
│   ├── UiSettings.kt      可观察的设置状态（即时刷新）
│   └── Models.kt
└── ui/
    ├── ShelfScreen.kt     书架 / 在读页、排序、列数
    ├── ReaderScreen.kt    阅读器与点击翻页层
    ├── WebtoonScreen.kt   卷轴模式（超长条漫分块）
    ├── SettingsSheet.kt   设置面板
    ├── Backdrop.kt        设置卡片的毛玻璃快照
    ├── Motion.kt          动效曲线、时长与连续 selection 工具
    └── Components.kt      胶囊按钮、连续式分段选择器等
```
