一款安卓本地漫画阅读器：直接读取手机文件夹里的漫画包，点开即看，不把图片解压到磁盘。

支持 Android 8.0（API 26）到最新版本。界面采用 Material 3 Expressive 风格。

---

## 主要功能

- 选一次漫画文件夹，长期记住；打开应用就是书架
- Material 3 底部图标导航（书架 / 在读，图标 + 文字 + 跟手滑动的选中指示器），可点击切换，也可左右滑动切换；在读页只显示翻过页且未看完的漫画（只打开封面、或翻回第一页都视为未读）
- 书架可选每排 2 / 3 / 4 / 5 本（默认 2），列数多时封面卡片自动紧凑排版
- 7 种排序：名称升/降、修改时间新/旧、体积大/小、最近阅读；搜索框旁下拉即选
- 可折叠大标题栏：标题字号 / 字重 / 透明度随滚动连续插值，工具栏固定不消失，收到底只留搜索框与排序 / 列数 / 刷新 / 设置；下滑反向渐进展开；滚动后出现「回到顶部」圆形按钮；两页各自保留滚动位置
- 自动扫描 `.zip` / `.cbz` / `.rar` / `.7z` **和已经解压出来的图片文件夹**（都含子文件夹，几种可以混在同一个目录里），封面缩略图、搜索、真实阅读进度（第 x / y 页 + 进度条；翻过页才记录，翻回第一页清除记录视为未读，返回书架立即刷新）
- 文件夹类漫画与压缩包完全同权：直接列目录里的图片按文件名自然排序当页，不复制、不搬动、不生成任何临时文件，页数和进度照样记录；书架上用「文件夹」代替体积显示
- **可以添加多个漫画文件夹**（设置 →「漫画文件夹」→ 添加），机身存储、SD 卡、按作者或按类型分开放的书库会汇总到同一个书架；`zip`、`rar`、`7z`、图片文件夹混着放也没关系
- **按分类筛选**：每个文件夹下的第一层目录名自动成为书架的「分类」筛选（作者名、类型名、系列名都行），点一下只看这一类
- 书架索引持久化：冷启动先显示记住的书架，后台静默增量核对，几千本也不用等重新整理；「刷新」按钮可立即重查；扫描上限 10 万本、目录深度 12 层
- 封面跨启动缓存 + 按列数降采样（160～360 px）+ 并发生成限流，一排 5 本也不卡顿
- 动效遵循「连续状态」原则：指示器跟手滑动并带形状挤压，颜色 / 圆角 / 字号由同一个连续进度插值；页面水平推入带视差，短促 ease-out + 形状形变，并尊重系统「减少动画」设置
- 不解压直读，支持 ZIP64 大包（> 4 GB）
- 自动识别 UTF-8 / GBK / Shift_JIS 文件名，中文、日文包名不乱码
- 页码按自然顺序排（`第2页` 在 `第10页` 前面），自动跳过说明文件
- 支持 jpg / png / webp / gif / bmp / heic / avif 等常见格式
- 右→左（日漫）或左→右翻页、单页 / 双页、轻点左右边缘**可快速连点**翻页（可关，带方向反馈）、双指缩放、双击复原
- **两种阅读模式**：翻页（单页 / 双页、左右方向）与**卷轴**（连续下滑，专为韩国条漫等超长图设计）。卷轴模式把几万像素高的长图按约 1000 px 切成小块，只解码屏幕上能看到的那几块，页与页之间无缝衔接；打开书时只扫描图片头（每页约 64 KB）就能算出整本的长度
- 卷轴模式下：上下滑动连续阅读、点左右侧滚动一屏、页数条跳页、首页 / 上一页 / 下一页 / 末页；进度同样按「当前所在的那一页」记录，滑回第一页即视为未读
- **缩放方式七选一**，翻页与卷轴都生效：原始尺寸（1:1 像素）、符合屏幕（整页可见）、符合宽度、符合高度、固定缩放（40%–400% 可调）、伸展（填满、不保比例）、覆盖（填满、保比例、裁掉多余）；页面比屏幕大时可直接拖动查看，窄边不足时滑动手势仍用于翻页
- **默认锁定竖屏，侧躺不翻转**：软件自己锁定画面方向，不再跟着手机重力把界面转成横屏，侧躺、躺着看都不会突然横过来。想横屏看双页，点阅读器右上角的「切横屏」一键切换，再点「切竖屏」切回；设置里仍可选「跟随系统」恢复自动旋转
- 其它阅读选项：**原点设置**（水平置中 / 靠左 / 靠右）、**屏幕方向**（直立 / 横屏 / 跟随系统）、**图像平滑方式**（平滑 / 锐利）、**背光控制**（跟随系统，或只在应用内单独调亮度，不改系统设置）
- **收藏**：在书架**长按漫画封面**弹出菜单，点「收藏」后封面右上角会出现一颗粉色爱心；再长按一次可以取消。收藏单独保存，清除阅读进度不会把收藏一起清掉
- **书架筛选**：书架顶部工具栏的「全部 / 已读完 / 正在读 / 收藏」是一个胶囊按钮，点一下弹出菜单选择，选中后按钮高亮；按阅读进度或收藏过滤，和搜索、分类、排序可以叠加使用；「在读」标签页本身已是筛选后的列表，不再重复过滤
- **清除进度防误触**：「清除所有阅读进度」要**连续点 3 次**（间隔超过 2 秒会重新计数）才弹出警告框，警告框出现后**看满 3 秒**才能点「确认清除」；按钮上会显示还差几次、确认按钮上会显示剩余秒数
- **设置分两层**：书架右上角打开的是设置菜单（阅读设置 / 漫画文件夹 / 个性化 / 书架列数 / 清除进度 / 关于），阅读项统一收进「阅读设置」子页，个性化项收进「个性化」子页；阅读器里的齿轮按钮直接跳到阅读设置。窗口是居中的**毛玻璃悬浮窗**（不是全屏面板，也不铺满整块屏幕）：只有窗口范围内的画面是虚化的，窗口以外保持清晰，文字不会压在花纹上，改一项也能立刻看到周围的画面变化
- **返回键分层**：阅读时按返回先关设置窗口，再收起工具条，最后才退出到书架
- 阅读器底部控制栏：可横向滑动的**页面缩略图预览**（点选跳页、当前页高亮、独立小图缓存）、日漫模式**镜像页数条**与两端页码、首页 / 上一页 / 下一页 / 末页、单双页与方向快捷切换、收起工具条
- 所有设置即时生效（单一可观察状态源），自动记住看到第几页，屏幕常亮，全屏沉浸
- **六套清新主题颜色**：抹茶绿（默认）、湖水青、晴空蓝、薰衣草、樱花粉、蜜桔橙。低饱和的浅色纸面 + 明亮干净的点缀色，不把整块背景染成深色；按钮、选中态、进度条、分段控件一起变色，浅色 / 深色各有一套对应配色，切换时颜色渐变过渡
- **四种翻页动画**（在「阅读设置」里选）：滑动（默认，横向推开）、淡入淡出、翻书（新页绕书脊 3D 翻入）、缩放（轻微放大显现）。翻书时书脊固定在同一侧，往回翻是同一个翻页动作反着放，不会镜像到屏幕另一边；换到「右 → 左（日漫）」时书脊移到右边，但**翻到下一页一律从下往上翻上来、翻回上一页一律从上往下翻下去**，两种方向下视觉逻辑一致；翻页时下方始终压着一整张已显示的页面，所以动画中途不会出现黑屏；点两侧翻页、滑动翻页、页码条跳页都能看到；卷轴模式是连续滚动，不参与翻页动画
- 浅色 / 深色 / 跟随系统
- 高清大图按屏幕降采样 + 像素预算，避免闪退；相邻页预取

## 权限与隐私

只申请 `INTERNET` 权限，仅用于「关于软件 → 检测更新」读取公开的 GitHub 发布页。不申请任何存储权限，不会上传漫画、文件名或设备信息。文件访问通过系统自带的文件夹选择器授权，只对用户选定的目录生效。

## 超长条漫

在「阅读设置 → 阅读模式」里选**卷轴**（阅读器底部工具条也有快捷按钮），然后：

1. 直接上下滑动，整本连续往下走，不用一页一页点。
2. 点屏幕左 / 右侧滚动一屏，点中间显示或收起工具条；底部页数条可以跳到任意一话。
3. 条漫建议保持默认「直立」+「符合宽度」；图片比屏幕窄时用「原点设置」调对齐。

也提供**横向卷轴**模式，适合左右连续阅读。

## 支持范围

| 项目 | 说明 |
| --- | --- |
| 压缩包 | `.zip`、`.cbz`（含 ZIP64 大包） |
| RAR | `.rar`（RAR 4 / RAR 5，含 solid 压缩） |
| 7z | `.7z`（LZMA / LZMA2，solid 压缩也支持） |
| 图片文件夹 | 目录里直接放图片即可（jpg / png / webp…），页序按文件名自然排序；子目录里有图片的，按「一层一个作品」识别 |
| 图片 | jpg / png / webp / gif / bmp / heic / heif / avif / jxl / tiff（实际取决于系统解码器） |
| 不支持 | 分卷包 / 加密或带密码的压缩包 / 非标准压缩算法 |
| 文件夹位置 | 手机内部存储、SD 卡的普通文件夹最佳 |
| 云盘目录 | 少数云盘提供的文件无法"跳着读"，会提示改用普通文件夹 |
| 单页体积 | 展开后超过 96 MB 的单张图片会拒绝加载，避免内存溢出 |
| 超长条漫 | 请用卷轴模式；几万像素高的长图会自动分块。HEIF / AVIF 长图会降级为「整图缩小后裁切」，清晰度较低 |
